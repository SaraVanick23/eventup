# EventUp

EventUp is a frontend web application built with React for browsing events 
and viewing event details.

This project was originally developed as part of an academic assignment in 
Brazil, so the application interface is currently in Portuguese.

## Features

- Browse available events
- View event details
- Navigate between pages
- Login interface

## Technologies

- React
- JavaScript
- CSS
- React Router

## Project Structure

The project is organized into reusable components and pages, including:

- Home
- Events
- Event Details
- Login
- Navbar
- Footer

## How to Run

1. Clone the repository.
2. Install the dependencies:

   npm install

3. Start the application:

   npm start
